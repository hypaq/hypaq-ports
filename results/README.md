# Reference results

`reference_results.json` is generated by `generate_reference.py` from the supplied
synthetic data. It contains measured classical enumeration outputs, not invented
quantum results. It is deterministic and intentionally excludes wall-clock timing.

The berth solver proves optimality by enumerating all allowed combinations.
The separate QUBO sweep evaluates all 256 bitstrings; the Ising comparison includes
the constant offset. The crane solver checks all 81 idle/vessel allocations.

Replanning compares the original plan with two updated plans. Multiple optimal
plans exist. The stability example depends on documented input-order tie-breaking:
free optimization may choose two changes, whereas weighted optimization finds one.
This illustrates selecting among equivalent waiting-time optima, not a general
claim that stability penalties always improve operations.

Run from the repository root:

```bash
PYTHONPATH=src python results/generate_reference.py
```

Outputs record the package and Python versions, instance IDs and configuration.
If regenerated under another Python version, the recorded environment changes.
Runtime, sampling quality, quantum resources and industrial KPIs require later
experiments and are not reported by this starter.
